# 🌲 Тополь — Table Sync Engine

Автоматический пинг-понг статусов между 4 таблицами Google Sheets по 9 шагам цепочки движения видео-контента.

## 🎯 Что делает

Автоматизирует конвейер производства видео:
- Сценарий → клиент → сценарист → менеджер → монтажёр → клиент
- Проверяет статусы каждые 5 минут
- Сохраняет историю в PostgreSQL
- Показывает состояние через Web UI

## 📊 Таблицы

| # | Таблица | Вкладок | Описание |
|---|---------|---------|----------|
| 1 | **Номос Сценарии** | 4 | Основной хаб: сценарии, анализ, архив |
| 2 | **Спр_Монтаж** | 6 | Сценарии, монтажёры, клиенты, задания |
| 3 | **AI4 отчёт Номос** | 7 | Доступы, статистика, выгрузки |
| 4 | **Монтажёр Михаил** | 4 | Задания конкретному монтажёру, оплата |

## ⚡ 9 шагов цепочки

1. **Сценарий одобрен** → копирование в клиентскую таблицу
2. **Пинг-понг сценарист ↔ клиент** — синхронизация правок
3. **Дедлайн + исходник + готово** → уведомление менеджеру
4. **Пинг-понг менеджер ↔ сценарист** — одобрение исходника
5. **Выбор монтажёра** → задание в таблицу монтажёра
6. **Пинг-понг монтажёр ↔ менеджер** — статус монтажа
7. **Монтаж одобрен** → отправка клиенту
8. **Клиент одобрил** → ссылка сценаристу
9. **Сценарист: дата + описание** → финальное обновление

## 🏗 Стек

- **Python 3.12** + Google Sheets API
- **APScheduler** — каждые 5 минут
- **PostgreSQL 16** — дубляж данных
- **FastAPI + Jinja2** — Web UI на порту 18889
- **Docker Compose** — 3 контейнера

## 🚀 Быстрый старт

```bash
# 1. Положить service_account.json в корень
# 2. Запустить
docker compose up -d --build

# 3. Проверить
curl http://localhost:18889/
curl http://localhost:18889/api/health
```

## 📡 API


- 9 шагов с индикацией (зелёный = есть движение)
- Форма прямого запроса к любой таблице

## 📁 Структура

```
.
├── config.py          # Таблицы, вкладки, шаги цепочки
├── engine.py          # Движок: Google Sheets клиент + логика шагов
├── scheduler.py       # APScheduler: запуск engine каждые 5 минут
├── ui.py              # FastAPI Web UI + API эндпоинты
├── docker-compose.yml # 3 сервиса: engine, ui, postgres
├── Dockerfile
├── requirements.txt
├── sql/init.sql       # PostgreSQL схема
└── logs/state.json    # Кеш состояния (авто-обновляется)
```

## 🔧 Конфигурация

Менять в `config.py`:
- `SHEETS` — ID таблиц и названия вкладок
- `WORKFLOW` — триггеры и действия для каждого шага
